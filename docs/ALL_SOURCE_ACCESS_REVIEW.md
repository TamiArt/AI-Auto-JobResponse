# Аудит условий источников вакансий JOBOS

Проверено: 12 октября 2026 года.

Это проверка опубликованных официальных документов, а не юридическое заключение. Публичный endpoint сам по себе не означает разрешения на массовый сбор, хранение или коммерческую републикацию вакансий.

## Легенда

- **Разрешение по опубликованным правилам подтверждено** — источник явно допускает обычное использование своего API/feed в стороннем продукте при соблюдении условий.
- **Нужно согласование** — есть API, но использование JOBOS как агрегатора ограничено, либо требуется активация, ключ или подтверждение условий.
- **Только внешняя ссылка** — JOBOS отправляет пользователя на сайт источника и не копирует его данные.
- **Не подключать пока** — доступ/право использования/покрытие не подтверждены.

## Внешние ссылки без сбора вакансий

Следующие источники в текущем реестре являются поисковыми ссылками, а не автоматическими API-интеграциями: LinkedIn Jobs, Indeed, Glassdoor, Wellfound, Djinni, EURES, USAJOBS, Behance Jobs, Dribbble Jobs, ArtStation Jobs, Upwork, Freelancer и Kwork. Для них JOBOS должен открывать оригинальный поиск и не копировать данные. Если позже потребуется автоматическая интеграция, условия API/партнёрской программы нужно проверять отдельно; публичная страница поиска не является разрешением на скрейпинг.

## Практическое решение

### Разрешение по опубликованным правилам подтверждено
- Работа России — open data, с соблюдением условий и атрибуцией.
- Remote OK — бесплатный feed, источник и ссылка на оригинальную вакансию.
- Jobicy public API — бесплатный endpoint, canonical URL, атрибуция, синхронизация не чаще раза в час.
- Arbeitnow public API — бесплатный endpoint без ключа, обязательна обратная ссылка; разрешение может быть отозвано.

### Требуется подтверждение до общей автоматической выдачи
- WWR — прямой запрет job-search service без согласования.
- Remotive — ограничение на передачу вакансий сторонним job-сайтам.
- HH.ru — регистрация/согласование приложения и выяснение причины 403.
- SuperJob — ключ приложения и подтверждение тарифа/условий.
- Habr Career — OAuth и активация; запросы должны отражать действие пользователя.
- Telegram — права на сбор и повторное использование постов, включая ограничения AI/ML.
- Remocate и Remote.co — актуальная документация и условия.
- ATS-провайдеры — доступ в основном к вакансиям конкретных работодателей, не ко всему рынку.

### Пока только внешние ссылки
Авито Работа, Работа.ру, Зарплата.ру, GeekJob, Finder.work, Getmatch и все перечисленные международные ручные поиски.

### Не подключать в текущем виде
- Adzuna — RU-покрытие не подтверждено, постоянное коммерческое использование может потребовать лицензию.
- Jooble для РФ — рынок не подтверждён, бесплатная квота ограничена 500 запросами на ключ за всё время.
- Jobicy Commercial API — не нужен: бесплатный режим уже отдаёт ссылку на Jobicy; прямая ATS-ссылка через коммерческий режим стоит $0.01 за новую подходящую вакансию.

## Следующие действия в проекте

1. Не включать источники со статусом «требуется подтверждение» в автоматическую выдачу до ответа площадки.
2. В первую очередь согласовать WWR и Remotive; до ответа безопаснее оставить только внешние ссылки.
3. Для HH/SuperJob оставить явную обработку отсутствующего ключа и upstream-ошибок.
4. Для Jobicy использовать только бесплатный public endpoint.
5. Для ATS ограничиться опубликованными/listed вакансиями конкретных работодателей.
6. Вести в реестре источник условий, дату проверки, требования к атрибуции, ключу, цене и активации; повторять проверку перед релизами.
