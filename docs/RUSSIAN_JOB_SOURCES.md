# Российские источники вакансий — реестр интеграций

Последняя проверка: 12 октября 2026 года.

Этот список разделяет **реально подключённые адаптеры**, **готовые к настройке интеграции** и **источники, где сначала нужно получить разрешение**. Наличие сайта поиска или API для работодателей само по себе не означает, что JOBOS вправе получать общий каталог вакансий.

Общие правила для всех автоматических и внешних источников описаны в [SOURCE_USAGE_POLICY.md](./SOURCE_USAGE_POLICY.md). Этот реестр отражает интеграции российского рынка.

## Почему SuperJob добавлен первым

Официальная документация описывает поиск через GET https://api.superjob.ru/2.0/vacancies/ и указывает, что для использования API приложение нужно зарегистрировать и передавать ключ приложения в заголовке X-Api-App-Id. Для выдачи списка вакансий авторизация соискателя не требуется; доступ к контактам — отдельный вопрос. Наличие ключа не заменяет проверку актуальных лимитов и условий.

Ключ читается только на сервере из SUPERJOB_APP_ID. Он не хранится в исходниках, не передаётся браузеру и не должен попадать в Git. Пока переменная не настроена, адаптер возвращает явную ошибку конфигурации вместо пустой «успешной» выдачи. SuperJob не включён в автоматический первый экран по умолчанию, чтобы не создавать ошибку в обычном поиске до настройки доступа.

## Правила добавления новых источников

1. Сначала подтвердить официальный endpoint/feed и допустимость использования в агрегаторе.
2. Проверить необходимость регистрации, платной подписки, OAuth, секретов и лимитов.
3. Если доступ зависит от ключа, хранить его только в server-side environment variables; не включать такой источник в стандартный поиск до настройки.
4. Проверить live-ответы, безопасные ссылки, обязательные поля, дату, зарплату, удалённость и корректное поведение при 401/403/429/timeout.
5. Добавить fixture/contract tests и проверить обе среды: Vercel API и self-hosted Node server.
6. Не использовать CAPTCHA bypass, закрытые endpoints, скрытый scraping или платный scraping-as-a-service.
